# SHA CORE AI

**A Personal AI Chatbot Platform Built by Shahan Ali**

SHA CORE AI is an AI-powered chatbot built using Python, Flask, and Google Gemini API. It provides a modern chat interface with chat history and session-based privacy.

## Features

- AI-powered conversations
- Chat history
- Create new chats
- Rename and delete conversations
- Session-based chat privacy
- Modern dark navy and turquoise interface
- Responsive design

## Technologies Used

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript
- SQLite
